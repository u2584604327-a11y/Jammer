Jammer Privacy Policy

Effective October 2, 2026 · 生效日期：2026年10月2日
English简体中文Repository

English

Jammer is a local-first browser extension. It does not collect, sell, rent, upload, or transmit personal data to a Jammer-operated server.

Local data. Jammer stores protection state, network-blocking state, page-ad-cleanup state, language preference, and manually entered allowlist domains in local extension storage under jammerSettings.

No telemetry. Jammer has no account system, analytics, telemetry, advertising SDK, cloud sync, remote configuration, or runtime filter-list download service.

Network filtering. Network blocking uses Chromium declarativeNetRequest with packaged rules generated from pinned EasyList sources at build time. Jammer does not upload browsing or blocking logs.

Optional page-ad cleanup. This feature is off by default. When enabled, Jammer requests optional scripting and HTTP/HTTPS site access only to register packaged CSS-only cosmetic filtering. It is not intended to read or collect page text, forms, passwords, history, or cookies. Disabling the feature removes the optional site access.

Permissions. Required: declarativeNetRequest, storage. Optional for page cleanup: scripting, http://*/*, https://*/*.

Retention. Jammer operates no backend user database. Local settings remain until changed, browser/extension storage is cleared, or Jammer is uninstalled.

Full policy: PRIVACY.md. Privacy questions: GitHub Issues.

简体中文

Jammer是一个本地优先的浏览器扩展。Jammer不会向Jammer运营的服务器收集、出售、出租、上传或传输个人数据。

本地数据。 Jammer仅在扩展本地存储的jammerSettings中保存总保护状态、网络广告拦截状态、页面广告清理状态、语言偏好及用户手动输入的白名单域名。

无遥测。 Jammer没有账号系统、统计分析、遥测、广告SDK、云同步、远程配置或运行时过滤列表下载服务。

网络过滤。 网络拦截使用Chromium declarativeNetRequest，规则在构建阶段根据固定并校验过的EasyList来源生成并随扩展打包。Jammer不会上传浏览或拦截日志。

可选页面广告清理。 该功能默认关闭。启用时，仅为注入扩展内置CSS页面广告隐藏规则而请求可选scripting及HTTP/HTTPS网站访问权限；不会主动读取或收集网页正文、表单、密码、浏览历史或Cookie。关闭后会移除相应可选权限。

权限。 必须：declarativeNetRequest、storage。页面清理可选：scripting、http://*/*、https://*/*。

保留。 Jammer不运营用户后端数据库。本地设置会保留到用户修改、清理浏览器/扩展存储或卸载Jammer为止。

完整政策：PRIVACY.md。隐私问题：GitHub Issues。
