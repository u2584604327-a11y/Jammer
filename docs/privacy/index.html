Jammer Privacy Policy

Effective October 2, 2026 · 生效日期：2026年10月2日
English简体中文Repository

English

Jammer is local-first. It has no account, analytics, telemetry, cloud sync, or runtime filter-update service, and does not upload personal browsing data to a Jammer-operated server.

Local settings. jammerSettings can contain protection, ad-blocking, privacy/tracker, known-phishing, optional HTTPS-upgrade, page-cleanup and content-filter states; selected content categories; language preference; ad allowlist; content exceptions; and manually blocked domains.

Ads and scripts. Packaged EasyList-derived DNR rules block known ad servers plus broader banner, path, script, image, frame, stylesheet, XHR and related ad requests. Lists are pinned and compiled at build time.

Privacy / trackers. A separate EasyPrivacy-derived DNR ruleset blocks known tracking scripts, pixels, XHR, pings, frames and similar endpoints. Blocked-request logs are not uploaded.

Known phishing. A pinned Phishing-Database active-domain snapshot is compiled into navigation-blocking rules. It blocks top-level and embedded navigation to listed domains, including redirects that land on them. The installed extension does not query the source at runtime.

Manual dangerous-site list. User-entered domains are stored locally and blocked for top-level or embedded navigation.

DNS boundary. Jammer does not inspect raw DNS answers and cannot reliably identify hostname-preserving DNS poisoning. Browser/OS Secure DNS or DNS-over-HTTPS remains a separate layer.

Optional HTTPS upgrade. Disabled by default. If enabled, Jammer requests optional HTTP/HTTPS site access and installs a local upgradeScheme rule for page/frame navigation. Legacy HTTP-only sites may stop loading until this feature is disabled.

Optional page cleanup. Disabled by default. When enabled, Jammer requests optional scripting plus site access to apply packaged generic and site-specific cosmetic rules. A local helper may inspect element markers, link/image URLs and image dimensions to hide stubborn banner ads; it does not upload those page signals.

Optional content filtering. Disabled by default. Selected categories are matched locally against bounded visible text, labels, link/media URL metadata, and pinned local gambling/explicit domain signals. Only matched content blocks are hidden. Scanned page data and matched terms are not uploaded. False positives and false negatives are possible.

Badware / abusive scripts. A separate packaged ruleset is compiled at build time from pinned uBlockOrigin/uAssets badware and resource-abuse sources. It blocks many known malicious, credential-stealing, miner and abusive network requests without runtime list downloads.

Permissions. Required: declarativeNetRequest, storage. Optional: scripting, http://*/*, https://*/*. Jammer does not request tabs, history, cookies, webRequest, debugger, downloads, or nativeMessaging.

Runtime egress. Jammer extension pages use connect-src 'none'. Rule-source network access happens in build scripts, not in the installed extension.

Full policy: PRIVACY.md. Privacy questions: GitHub Issues.

简体中文

Jammer坚持本地优先：没有账号、统计分析、遥测、云同步或运行时规则更新服务，也不会把个人浏览数据上传到Jammer运营的服务器。

本地设置。 jammerSettings可保存总保护、广告拦截、隐私/跟踪器、已知钓鱼网站、可选HTTPS升级、页面广告清理和内容过滤状态，以及所选类别、语言、广告白名单、内容过滤例外与手动危险域名。

广告与广告脚本。 随扩展打包的EasyList衍生DNR规则会拦截已知广告域名，以及更广泛的横幅、路径、脚本、图片、框架、样式、XHR等广告请求；规则在构建阶段固定版本并编译。

隐私 / 跟踪器。 独立EasyPrivacy衍生规则用于阻止已知跟踪脚本、像素、XHR、Ping、框架等端点，不上传拦截日志。

已知钓鱼网站。 固定的Phishing-Database活跃域名快照会在构建阶段转换为导航拦截规则，阻止顶层/嵌入页面进入名单域名，包括最终落到名单域名的跳转。安装后的扩展不会运行时查询该数据源。

手动危险网站列表。 用户输入的域名只保存在本地，并用于阻止顶层或嵌入页面导航。

DNS边界。 Jammer不检查原始DNS解析结果，无法可靠识别“主机名不变但被解析到恶意IP”的DNS污染。浏览器/操作系统的安全DNS或DoH仍是独立保护层。

可选HTTPS升级。 默认关闭。启用后会请求可选HTTP/HTTPS网站访问权限，并仅对页面/框架导航使用本地upgradeScheme规则。仅支持HTTP的旧网站可能暂时无法打开。

可选页面广告清理。 默认关闭。启用时请求可选scripting和网站访问权限，以应用通用及站点专用页面广告规则。本地辅助逻辑可能检查元素标记、链接/图片URL和图片尺寸来隐藏顽固横幅，但不会上传这些页面信号。

可选内容过滤。 默认关闭。所选类别仅在本地匹配有限可见文字、标签、链接/媒体URL元数据以及固定的本地赌博/露骨内容域名信号，只隐藏命中的内容块；页面数据和匹配词不会上传，可能存在误判或漏判。

恶意 / 滥用脚本。 独立规则集在构建阶段从固定的uBlockOrigin/uAssets坏件与资源滥用来源生成，可拦截大量已知恶意、盗号、挖矿及资源滥用网络请求；运行时不下载规则列表。

权限。 必须：declarativeNetRequest、storage。可选：scripting、http://*/*、https://*/*。Jammer不请求tabs、history、cookies、webRequest、debugger、downloads或nativeMessaging。

运行时联网边界。 Jammer扩展页面使用connect-src 'none'。第三方规则来源只由构建脚本获取，不由安装后的扩展获取。

完整政策：PRIVACY.md。隐私问题：GitHub Issues。
