Jammer Privacy Policy

Effective October 2, 2026 · 生效日期：2026年10月2日
English简体中文Repository

English

Jammer is a local-first browser extension. It does not collect, sell, rent, upload, or transmit personal data to a Jammer-operated server.

Local data. Jammer stores protection state, network-blocking state, page-ad-cleanup state, content-filter state and selected categories, language preference, ad-block allowlist domains, and content-filter exception domains in local extension storage under jammerSettings.

No telemetry. Jammer has no account system, analytics, telemetry, advertising SDK, cloud sync, remote configuration, or runtime filter-list download service.

Network filtering. Network blocking uses Chromium declarativeNetRequest with packaged rules generated from pinned EasyList sources at build time. Jammer does not upload browsing or blocking logs.

Optional page-ad cleanup. This feature is off by default. When enabled, Jammer requests optional scripting and HTTP/HTTPS site access to register packaged CSS-only cosmetic filtering.

Optional content filtering. This feature and every category are off by default. When enabled, Jammer locally inspects a limited amount of the page title, description, headings, and visible body text and applies packaged weighted keyword rules for gambling, explicit sexual material, graphic violence, scam-like promotion, and clickbait/nuisance content. Page text and matched terms are not uploaded to a Jammer server. False positives and false negatives are possible.

Permissions. Required: declarativeNetRequest, storage. Optional for page cleanup or content filtering: scripting, http://*/*, https://*/*.

Retention. Jammer operates no backend user database. Local settings remain until changed, browser/extension storage is cleared, or Jammer is uninstalled.

Full policy: PRIVACY.md. Privacy questions: GitHub Issues.

简体中文

Jammer是一个本地优先的浏览器扩展。Jammer不会向Jammer运营的服务器收集、出售、出租、上传或传输个人数据。

本地数据。 Jammer仅在扩展本地存储的jammerSettings中保存总保护状态、网络广告拦截状态、页面广告清理状态、内容过滤状态与所选类别、语言偏好、广告白名单域名及内容过滤例外域名。

无遥测。 Jammer没有账号系统、统计分析、遥测、广告SDK、云同步、远程配置或运行时过滤列表下载服务。

网络过滤。 网络拦截使用Chromium declarativeNetRequest，规则在构建阶段根据固定并校验过的EasyList来源生成并随扩展打包。Jammer不会上传浏览或拦截日志。

可选页面广告清理。 该功能默认关闭。启用时会请求可选scripting及HTTP/HTTPS网站访问权限，以注册扩展内置CSS页面广告隐藏规则。

可选内容过滤。 该功能和每个类别默认都关闭。启用后，Jammer会在设备本地检查有限范围的网页标题、描述、标题文字和可见正文，并使用扩展内置的加权关键词规则识别赌博/博彩推广、露骨色情、血腥/严重暴力、疑似诈骗诱导及标题党/诱导内容。网页正文和匹配词不会上传到Jammer服务器，且可能出现误判或漏判。

权限。 必须：declarativeNetRequest、storage。页面清理或内容过滤可选：scripting、http://*/*、https://*/*。

保留。 Jammer不运营用户后端数据库。本地设置会保留到用户修改、清理浏览器/扩展存储或卸载Jammer为止。

完整政策：PRIVACY.md。隐私问题：GitHub Issues。
