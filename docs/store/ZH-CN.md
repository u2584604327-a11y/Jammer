# Jammer 商店上架文案 — 简体中文

## 产品名称

Jammer

## 简短说明

本地优先的广告/广告脚本与跟踪器拦截扩展，支持已知钓鱼网站导航保护、可选HTTPS升级、页面广告清理和本地内容块遮蔽。

## 详细说明

Jammer 是一个基于 Manifest V3 的本地优先浏览器扩展，用于拦截网络广告，并在用户主动启用后隐藏明确识别出的页面广告容器。

网络拦截使用 Chromium 的 declarativeNetRequest 引擎。EasyList 来源在构建阶段固定版本、校验并编译，扩展运行时不会远程下载过滤列表。

“页面广告清理”是可选功能。启用时，Jammer 会请求网站访问权限，并使用扩展内置 CSS 与本地元素启发式规则清理自托管和动态插入广告；关闭该功能后，会撤销相应网站访问权限。Jammer 不使用这一能力读取网页正文、表单、密码、浏览历史或 Cookie。

主要功能：
- 网络广告拦截
- 内置隐私 / 跟踪器拦截
- 内置已知钓鱼网站导航拦截
- 可选HTTP→HTTPS导航升级
- 本地手动危险域名拦截
- 可选页面广告清理
- 用户主动开启的本地内容过滤：赌博/博彩推广、露骨色情、血腥/严重暴力、疑似诈骗诱导、标题党/诱导内容
- 只遮蔽命中的网页内容块，并显示匹配类别、匹配信号及显示/退出控制
- 独立的内容过滤例外列表
- 本地白名单管理
- 自动 / 中文 / English 界面语言
- 可撤销的网站访问权限
- 设置仅保存在本地
- 无遥测
- 无统计分析
- 无账号系统
- 无云同步
- 无远程代码
- 运行时不下载过滤列表

扩展必须权限仅为 declarativeNetRequest 与 storage。“页面广告清理”或“内容过滤”仅在用户主动开启后使用可选的 scripting 与 HTTP/HTTPS 网站访问权限；HTTPS导航升级只在用户主动开启后使用可选HTTP/HTTPS网站访问权限。内容过滤只在设备本地处理有限范围的网页可见文本，不会把网页正文上传到Jammer服务器。

Jammer 的设计重点是：权限明确、操作可逆、过滤来源可审计，并尽量使用浏览器原生机制完成拦截。

## 隐私摘要

Jammer 的设置保存在浏览器扩展本地存储中。项目不提供账号服务、统计分析服务、遥测接口、云同步服务或远程过滤规则更新服务。

可选的网站访问权限仅用于用户主动启用的页面清理/内容过滤或HTTPS导航升级，不用于收集浏览历史。
