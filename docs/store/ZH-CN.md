# Jammer 商店上架文案 — 简体中文

## 产品名称

Jammer

## 简短说明

本地优先的广告拦截扩展，支持网络广告过滤、可选页面广告清理、本地设置与透明可控的权限管理。

## 详细说明

Jammer 是一个基于 Manifest V3 的本地优先浏览器扩展，用于拦截网络广告，并在用户主动启用后隐藏明确识别出的页面广告容器。

网络拦截使用 Chromium 的 declarativeNetRequest 引擎。EasyList 来源在构建阶段固定版本、校验并编译，扩展运行时不会远程下载过滤列表。

“页面广告清理”是可选功能。启用时，Jammer 会请求网站访问权限，并仅注入扩展内置的 CSS 规则进行页面广告元素隐藏；关闭该功能后，会撤销相应网站访问权限。Jammer 不使用这一能力读取网页正文、表单、密码、浏览历史或 Cookie。

主要功能：
- 网络广告拦截
- 可选页面广告清理
- 本地白名单管理
- 自动 / 中文 / English 界面语言
- 可撤销的网站访问权限
- 设置仅保存在本地
- 无遥测
- 无统计分析
- 无账号系统
- 无云同步
- 无远程代码
- 运行时不下载过滤列表

扩展必须权限仅为 declarativeNetRequest 与 storage。“页面广告清理”仅在用户主动开启后使用可选的 scripting 与 HTTP/HTTPS 网站访问权限。

Jammer 的设计重点是：权限明确、操作可逆、过滤来源可审计，并尽量使用浏览器原生机制完成拦截。

## 隐私摘要

Jammer 的设置保存在浏览器扩展本地存储中。项目不提供账号服务、统计分析服务、遥测接口、云同步服务或远程过滤规则更新服务。

可选的网站访问权限只用于用户启用“页面广告清理”后应用扩展内置的 CSS 过滤规则。
